## 2. Judul, Tema SDGs, dan Sasaran Pengguna

### 2.1 Judul Proyek
**Teman Ceritamu — Ruang Aman: Website Edukasi Anti-Bullying dan Kesehatan Mental.**

Website ini dirancang sebagai media informasi yang membantu pengguna mengenali perundungan, memahami dampaknya, dan mengetahui langkah yang dapat dilakukan ketika mengalami atau menyaksikan *bullying*.

### 2.2 Tema SDGs
Proyek ini mengangkat tema pencegahan perundungan dan peningkatan kesadaran mengenai kesehatan mental yang berkaitan dengan tiga tujuan *Sustainable Development Goals* (SDGs):

* **SDG 3 — Kehidupan Sehat dan Sejahtera (*Good Health and Well-Being*)**
  Mendukung peningkatan kesadaran tentang kesehatan mental dan kesejahteraan, khususnya dalam memahami dampak perundungan terhadap kondisi psikologis seseorang.
* **SDG 4 — Pendidikan Berkualitas (*Quality Education*)**
  Mendorong terciptanya lingkungan pendidikan yang aman, inklusif, dan mendukung proses belajar tanpa perundungan.
* **SDG 16 — Perdamaian, Keadilan, dan Kelembagaan yang Tangguh (*Peace, Justice and Strong Institutions*)**
  Mendukung terciptanya lingkungan yang damai, aman, dan bebas dari kekerasan melalui peningkatan kesadaran serta kepedulian terhadap perilaku *bullying*.

### 2.3 Sasaran Pengguna
Sasaran utama website ini adalah **pelajar**, khususnya siswa sekolah, yang membutuhkan informasi mengenai *bullying* dan cara menghadapinya. Selain itu, website dapat dimanfaatkan oleh **guru, orang tua, dan masyarakat umum** sebagai sumber informasi awal untuk meningkatkan pemahaman mengenai perundungan, kesehatan mental, dan pentingnya menciptakan lingkungan yang saling menghargai.

## 3. Tujuan, Manfaat, dan Deskripsi Website

### 3.1 Tujuan Pengembangan
Website Teman Ceritamu dikembangkan dengan tujuan:
* Memberikan informasi mengenai pengertian, karakteristik, jenis, dan dampak *bullying*.
* Meningkatkan kesadaran tentang pentingnya menjaga kesehatan mental dan menghargai sesama.
* Memberikan panduan tindakan bagi individu yang mengalami, menyaksikan, atau pernah melakukan *bullying*.
* Menyediakan informasi mengenai pihak yang dapat dimintai bantuan ketika menghadapi perundungan.
* Mendorong terciptanya lingkungan belajar yang aman, nyaman, inklusif, dan bebas dari perundungan.
* Memanfaatkan teknologi web sebagai media penyampaian edukasi yang mudah diakses.

### 3.2 Manfaat Website
* **Bagi Pelajar:** Membantu mengenali berbagai bentuk *bullying* serta memahami langkah yang dapat dilakukan ketika menghadapi perundungan.
* **Bagi Saksi Perundungan:** Mendorong keberanian untuk mendukung korban dan mencari bantuan dengan cara yang aman.
* **Bagi Orang Tua dan Guru:** Menjadi bahan informasi awal untuk meningkatkan kepedulian terhadap perilaku perundungan di lingkungan sekitar.
* **Bagi Masyarakat:** Meningkatkan pemahaman mengenai pentingnya empati, kesehatan mental, dan hubungan sosial yang positif.
* **Bagi Pengembang:** Menjadi sarana penerapan HTML5 dan CSS3 dalam membangun website edukasi yang terstruktur, responsif, dan mudah digunakan.

### 3.3 Deskripsi Setiap Halaman
Website Teman Ceritamu terdiri atas lima halaman utama yang saling terhubung melalui navigasi.

#### A. Beranda (`index.html`)
Halaman Beranda merupakan halaman utama yang memperkenalkan website dan mengajak pengguna memahami pentingnya menciptakan lingkungan yang aman.
* **Fitur Utama:**
  * *Hero section* dengan pesan utama *"Setiap Orang Berhak Merasa Aman"*.
  * Pengenalan tujuan dan fokus website.
  * Kartu ilustrasi 4 jenis *bullying* (fisik, verbal, sosial, dan *cyberbullying*).
  * Informasi singkat mengenai dampak *bullying* terhadap kondisi psikologis, hubungan sosial, dan kegiatan belajar.
  * Tombol navigasi menuju halaman Edukasi dan Panduan.

#### B. Edukasi (`edukasi.html`)
Halaman Edukasi menyediakan informasi dasar mengenai *bullying* agar pengguna dapat mengenali bentuk perundungan dan memahami dampaknya.
* **Fitur Utama:**
  * Pengertian dan karakteristik *bullying*.
  * Penjelasan perbedaan konflik biasa, candaan, dan *bullying*.
  * Pembahasan *bullying* fisik, verbal, sosial/relasional, dan *cyberbullying*.
  * Tanda-tanda indikasi perundungan.
  * Penjelasan dampak terhadap kesehatan mental, fisik, hubungan sosial, dan pendidikan.
  * *Accordion* menggunakan elemen HTML `<details>` dan `<summary>` untuk menyajikan informasi yang dapat dibuka-tutup.

#### C. Panduan (`panduan.html`)
Halaman Panduan memberikan langkah-langkah yang dapat dipertimbangkan berdasarkan situasi yang dihadapi pengguna.
* **Fitur Utama:**
  * Panduan bagi individu yang mengalami *bullying*.
  * Panduan bagi saksi yang melihat *bullying*.
  * Panduan bagi individu yang pernah melakukan *bullying* dan ingin memperbaiki perilakunya.
  * Pesan dukungan untuk meningkatkan keberanian, empati, dan kepedulian.
  * Tab interaktif berbasis *radio input* dan CSS untuk memilih panduan sesuai situasi.
  * Tautan menuju halaman Bantuan.

#### D. Bantuan (`bantuan.html`)
Halaman Bantuan menyediakan informasi mengenai pilihan dukungan ketika pengguna mengalami atau mengetahui adanya perundungan.
* **Fitur Utama:**
  * Informasi pihak tepercaya (orang tua, wali, guru BK, pihak sekolah, dan tenaga profesional).
  * Informasi keamanan digital dan penanganan *cyberbullying*.
  * Direktori profil dukungan dengan *pemfilteran kategori* berbasis *radio input* dan CSS.
  * Tautan WhatsApp langsung pada profil yang mencantumkannya.
  * Contoh kalimat pembuka untuk memudahkan pengguna meminta bantuan.
  * Penjelasan batasan bahwa website merupakan media edukasi, bukan layanan konseling langsung/sistem pelaporan resmi.

#### E. Tentang (`tentang.html`)
Halaman Tentang menjelaskan latar belakang, tujuan, anggota kelompok, dan sumber informasi yang digunakan.
* **Fitur Utama:**
  * Latar belakang dan 3 fokus utama: edukasi, empati, dan penciptaan lingkungan aman.
  * Profil anggota kelompok beserta nama, NIM, dan foto.
  * Tautan referensi terpercaya (Alodokter, Kemenkes RI, Halodoc).
  * Ajakan untuk menyebarkan informasi pencegahan *bullying*.

## 5. Penjelasan Implementasi HTML dan CSS

### 5.1 Struktur HTML
HTML5 digunakan untuk membangun struktur setiap halaman dengan elemen semantik seperti `<header>`, `<nav>`, `<main>`, `<section>`, dan `<footer>`.

**Contoh kode navigasi (`nav`):**
```html
<nav class="nav-menu" id="navMenu">
  <a href="index.html" class="nav-link">Beranda</a>
  <a href="edukasi.html" class="nav-link">Edukasi</a>
  <a href="panduan.html" class="nav-link active">Panduan</a>
  <a href="bantuan.html" class="nav-link">Bantuan</a>
  <a href="tentang.html" class="nav-link">Tentang</a>
</nav>
```

### 5.2 CSS Variables dan Design System
Penggunaan CSS Variables pada selector `:root` di file `css/style.css` menjaga konsistensi komponen desain.

**Contoh CSS Variables:**
```css
:root {
  --primary-50: #eff6ff;
  --primary-500: #3b82f6;
  --primary-600: #2563eb;
  --mint-500: #14b8a6;
  --bg-body: #f8fafc;
  --bg-surface: #ffffff;
  --text-main: #0f172a;
  --text-muted: #475569;
  --radius-md: 12px;
  --radius-xl: 24px;
  --font-family: 'Plus Jakarta Sans', system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
}

body {
  font-family: var(--font-family);
  background-color: var(--bg-body);
  color: var(--text-main);
  line-height: 1.65;
  overflow-x: hidden;
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}
```

### 5.3 Implementasi Navigasi dan Hamburger Menu
Navigasi seluler memanfaatkan *Checkbox Toggle* (*Checkbox Hack*) menggunakan status `:checked` pada CSS untuk membuka menu tanpa JavaScript.

```css
.navbar-container {
  display: flex;
  align-items: center;
  justify-content: space-between;
  height: 72px;
  position: relative;
}
.nav-menu {
  display: flex;
  align-items: center;
  gap: 8px;
}
.nav-toggle-checkbox {
  position: absolute;
  opacity: 0;
  pointer-events: none;
}
```

### 5.4 Implementasi Flexbox
Digunakan untuk menyusun elemen dalam 1 dimensi (horizontal/vertikal).

```css
.card {
```

### 5.6 Responsive Design dan Media Queries
Layout menyesuaikan ukuran layar dengan breakpoint pada `1080px`, `1024px`, `768px`, dan `480px`.

```css
@media (max-width: 768px) {
  .hero-grid {
    grid-template-columns: 1fr;
  }
  .nav-menu {
    flex-direction: column;
  }
}
```

### 5.7 Accordion Menggunakan HTML dan CSS
Menggunakan elemen bawaan `<details>` dan `<summary>`.

```html
<details class="accordion-item">
  <summary>Apa yang dimaksud dengan bullying?</summary>
  <div class="accordion-content">
    <p>Bullying merupakan perilaku perundungan yang perlu dikenali dan ditangani dengan tepat.</p>
  </div>
</details>
```

```css
details.accordion-item {
  background-color: var(--bg-surface);
  border: 1px solid var(--border-light);
  border-radius: var(--radius-lg);
  overflow: hidden;
}
details.accordion-item[open] {
  border-color: var(--primary-300);
  box-shadow: var(--shadow-sm);
}
details.accordion-item summary {
  cursor: pointer;
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 20px 24px;
  font-weight: 700;
}
```

### 5.8 Tab Panduan Menggunakan Radio Input
Mekanisme navigasi tab tanpa JavaScript menggunakan `:checked` dan *sibling selector* `~`.

```css
.css-tabs-wrapper .tab-content {
  display: none;
}
#tab1:checked ~ .tab-content-1,
#tab2:checked ~ .tab-content-2,
#tab3:checked ~ .tab-content-3 {
  display: block;
  animation: fadeIn 0.3s ease;
}
```

### 5.9 Filter Kategori Bantuan Menggunakan CSS
Penyaringan kartu informasi bantuan berbasis status radio button dan pseudo-class `:not()`.

```css
#catBk:checked ~ .therapist-grid .therapist-card:not(.card-cat-bk) {
  display: none;
}
#catPsikolog:checked ~ .therapist-grid .therapist-card:not(.card-cat-psikolog) {
  display: none;
}
#catSebaya:checked ~ .therapist-grid .therapist-card:not(.card-cat-sebaya) {
  display: none;
}
```

### 5.10 Modal Menggunakan CSS `:target`
Menampilkan jendela modal interaktif saat elemen ditargetkan via fragment URL.

```css
.modal-overlay {
  position: fixed;
  inset: 0;
  opacity: 0;
  visibility: hidden;
  transition: opacity 0.3s ease, visibility 0.3s ease;
}
.modal-overlay:target {
  opacity: 1;
  visibility: visible;
}
```

### 5.11 Tipografi, Animasi, dan Aksesibilitas
* **Google Fonts:** Plus Jakarta Sans.
* **CSS Transitions & `@keyframes`:** Efek animasi mulus seperti `fadeIn`.
* **Aksesibilitas & Media:** Penggunaan `prefers-reduced-motion`, `object-fit: cover`, dan `max-width: 100%`.
